## Installation

1. Download the latest archive from the link above
2. Extract the contents into your `.minecraft` directory or Impact Client folder
3. Start Minecraft with the Impact Client profile selected
4. Open the Impact GUI (default key: Right Shift) and go to the Modules tab
5. Turn on the modules you want and set keybinds in the Controls menu

Example folder structure after extraction:
```
.minecraft/
  └── impact/
       ├── modules/
       ├── scripts/
       ├── configs/
       └── presets/
```

**How do I install the toolkit after downloading?**

**Will updates be delivered automatically?**  
No. You need to revisit the download page and fetch newer builds manually when they are released.

**Can I change which blocks X-Ray shows?**  
Yes. Open the X-Ray module settings and add or remove block IDs from the visible list.

**Is it usable on multiplayer servers?**  
A number of the features work on SMP servers, but some servers may forbid certain modules. Use it at your own discretion.

**Where are configuration files saved?**  
Your configs are stored in the `impact/configs/` subfolder. These files can be backed up or shared.

**Are JavaScript modules safe to run?**  
Scripts run inside the Impact Client environment. Only use modules from sources you trust.
